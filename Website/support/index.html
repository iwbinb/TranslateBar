Support

How can we help?

TranslateBar requires macOS 15 or later. Translation languages may need to download before their first use.

Translation does not start

Check that both languages are available on your Mac, then try a short sentence. macOS will prompt you if a required language resource needs to be downloaded.

Dictation is unavailable

Open System Settings → Privacy & Security and allow TranslateBar to use the microphone and speech recognition. Dictation is optional.

The keyboard shortcut does not work

Open TranslateBar Preferences and record a different shortcut. Another app may already be using the current combination.

Still need help?

Include your macOS version, TranslateBar version, and a short description of what happened. Please do not include text you consider private.
